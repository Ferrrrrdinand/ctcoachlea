# ⏱️ Aesthetic Countdown Timer

Countdown Timer modern dengan background grid biru sesuai gambar referensi Anda, animasi gelembung kaca 3D, dan panel kontrol di bagian bawah.

---

## 🚀 Cara Menjalankan

1. Buka folder: `f:\Pelayanan\COUNTDOWN`
2. Klik ganda (**Double Click**) file **`index.html`** di Google Chrome atau Microsoft Edge.
3. Countdown langsung tampil dengan background gambar grid biru Anda!

---

## 🎛️ Fitur & Pengaturan (Di Bagian Bawah)

- **Mulai / Jeda / Reset**: Tombol hijau `MULAI`, amber `JEDA`, dan `RESET`.
- **Atur Waktu**: Masukkan Menit & Detik secara manual, lalu klik `TERAPKAN`.
- **Preset Cepat**: Tombol `1M`, `3M`, `5M`, `10M`, `15M`, `+1M`, `+30S`, `-30S`.
- **Pilihan Background**:
  - 🖼️ **Background Grid Gambar (Default)**: Menggunakan gambar `background.jpg`.
  - 🟩 **Green Screen (#00FF00)**: Untuk Chroma Keying di OBS.
  - ⬛ **Transparent**: Khusus OBS Browser Source (tembus pandang).
  - 🟪 **Magenta Screen**: Alternatif chroma key.
- **Edit Teks Langsung**: Klik tombol `✏️ EDIT TEKS` untuk mengubah judul acara, nama pembicara, dsb.
- **Sembunyikan Panel Kontrol**: Tekan tombol `H` atau klik tab panel bawah untuk menyembunyikan kontrol agar tampilan bersih.

---

## ⌨️ Shortcut Keyboard

| Tombol | Aksi |
| :--- | :--- |
| **Spasi (Space)** | Mulai / Jeda (Start / Pause) |
| **R** | Reset Waktu |
| **H** | Sembunyikan / Tampilkan Panel Kontrol |
| **F** | Masuk / Keluar Fullscreen (Layar Penuh) |
